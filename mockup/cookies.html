Serviços de terceiros

  • Google Fonts. As letras do site são carregadas dos servidores da Google, que recebem o endereço IP do teu dispositivo. Recomendação: alojar as letras no próprio site antes de publicar, para evitar este envio.
  • Google Maps. Os links "mapa" abrem o site da Google Maps num separador novo. Nada é carregado enquanto não carregares no link.
  • Vídeos. Os vídeos estão alojados no próprio site e só carregam quando carregas em "play".
  • Mapa. O mapa dos pontos de recolha usa a biblioteca Leaflet (servida pela Cloudflare, cdnjs) e as imagens do mapa do OpenStreetMap, que recebem o endereço IP do teu dispositivo. O botão "Mais perto de mim" só pede a tua localização quando carregas nele, e a localização não sai do teu navegador.
  • Cartaz. O QR code do cartaz é gerado no teu navegador com uma biblioteca servida pela Cloudflare (cdnjs).

Como apagar tudo

Podes apagar os dados deste site nas definições do teu navegador (por exemplo, "Limpar dados de navegação" no Chrome ou "Gerir dados de sites" no Safari).

Sobre os dados que nos envias pelo formulário, lê a política de privacidade.
